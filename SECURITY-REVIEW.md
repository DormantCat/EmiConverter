# EMI Converter 1.0.11 — сведения для службы информационной безопасности

23 ноября 2026 года. Объект рассмотрения — переносимый EmiConverter.exe для Windows x64 и прилагаемые исходники C#.

## Назначение и обработка данных

Утилита локально разбирает выбранный файл EML, EMI, TXT или вставленный текст до 32 МиБ. Оператор видит отправителя, получателей, копии, адрес для ответа, тему, дату, тело, исходник и извлечённые ссылки. Значения заголовков отображаются из самого письма. Подключение к почтовому ящику отсутствует. Вложения не исполняются. В Windows предпросмотр формирует новый локальный HTML-документ из разрешённых тегов, свойств оформления и встроенных растровых изображений. Сохраняются таблицы, отступы и поддерживаемые стили письма. Адреса внешних ресурсов, обработчики событий, сценарии и активные ссылки исключаются из документа просмотра. Загрузки удалённых ресурсов и исполнения JavaScript в этом обработчике нет.

Письма и результаты проверок обрабатываются в памяти. Скопированные пользователем данные попадают в системный буфер обмена. Тема интерфейса сохраняется в пользовательском каталоге LocalApplicationData/EmiConverter/theme.txt. При запуске однофайловой сборки .NET может распаковать нативные компоненты в пользовательский временный каталог. В коде нет облачной синхронизации, телеметрии, фонового обновления или локального HTTP-сервера.

## Сетевые функции

Чтение письма работает локально. Оператор отдельно запускает сетевые функции. Команда «Проверить всё» инициирует DNS, доменную и сетевую регистрацию, трассировку и проверку TCP-сервисов, включая скрытые в интерфейсе разделы.

| Действие | Назначение и протокол | Что передаётся |
| --- | --- | --- |
| Справочники доменных зон | data.iana.org/rdap/dns.json и publicsuffix.org/list/public_suffix_list.dat, HTTPS | Запросы фиксированных справочников. Они кэшируются в памяти. |
| Регистрация домена | HTTPS к RDAP-реестру доменной зоны, при необходимости TCP 43 к WHOIS | Регистрируемый домен. Для неизвестного WHOIS-сервера IANA получает доменную зону. WHOIS передаёт запрос открытым текстом. |
| DNS | dns.google/resolve, HTTPS | Домен и тип записи или обратное имя IP для PTR. |
| Регистрация IP | rdap-bootstrap.arin.net и конечный региональный реестр, HTTPS | IP-адрес в пути запроса. |
| Перенаправления | Прямой GET к публичному HTTP(S)-адресу и целям перенаправления, TCP 80/443 | Хост, путь, параметры URL. Они могут содержать идентификаторы и секреты. Проверяются IP после DNS-разрешения. Cookies и HTTP-прокси отключены для этой функции. Ограничение — шесть перенаправлений. |
| Трассировка | В Windows через .NET Ping и ICMP, в Linux через собственный нативный модуль и UDP на порты 33435–33454 | Пробы до введённого IP и ответы промежуточных узлов. Внешние команды трассировки не вызываются. |
| Проверка сервисов | Выбранный IP, TCP 21, 25, 80, 110, 143, 443 | Попытки установить TCP-соединение без прикладного обмена. |

Встроенные WHOIS-адреса — whois.tcinet.ru, whois.denic.de, whois.nic.uk, whois.nic.io, whois.verisign-grs.com и whois.publicinterestregistry.org. Для поиска реестра используется whois.iana.org. Системный DNS используется для разрешения имён при исходящих соединениях. Для разделов «Регистрация IP-сети», «Маршрут» и «Доступность сервисов» имя цели также разрешается системным DNS, а не через dns.google. Сетевая диагностика принимает внутренние адреса. Имена или адреса, введённые оператором, могут передаваться внешним DNS/RDAP-сервисам.
