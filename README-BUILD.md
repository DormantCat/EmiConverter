# EMI Converter 1.0.11 — переносимая сборка C#

Для запуска проверенной версии на Windows 11 x64 достаточно одного файла EmiConverter.exe. Внутри опубликованного файла находятся WinForms и .NET 9.0.2. При первом запуске среда может распаковать нативные компоненты в пользовательский временный каталог. Главное окно использует исходную форму MainForm.cs. Тёмная тема включается при первом запуске, существующий выбор темы сохраняет приоритет.

## Сборка из исходников

Команды выполняются из каталога с build.proj. Для разработки требуется .NET SDK 9 и доступ к NuGet при первом восстановлении отсутствующих пакетов.

| Цель | Команда | Результат |
| --- | --- | --- |
| Windows x64 | `dotnet msbuild build.proj -p:Platform=windows` | dist/windows-x64/EmiConverter.exe |
| Windows 7 SP1 x64, экспериментальная цель | `dotnet msbuild build.proj -p:Platform=windows7` | Отдельная версия WinForms на .NET 6, dist/windows7-x64/EmiConverter.exe. Компиляция под .NET 6 подтверждена, запуск на целевой ОС не проверен. Поддержка .NET 6 завершена Microsoft в ноябре 2024 г. |
| Linux x64 | На Linux x64 выполнить `dotnet msbuild build.proj -p:Platform=linux` | Каталог dist/linux-x64. Перенести каталог целиком, запустить ./EmiConverter. Для сборки модуля трассировки требуется компилятор cc и заголовки Linux. |

Linux-интерфейс написан на C# с Avalonia. Для запуска необходим совместимый графический сеанс Linux и системные библиотеки графического стека. Установки .NET, браузера или сервера приложение не предусматривает. Для Linux подтверждена компиляция кода окна с Avalonia 11.1.3. Автономная публикация и запуск под Linux не проверены. В Linux-интерфейсе доступны текст письма и исходник, форматированный предпросмотр реализован для Windows.
